# 宿递 (Sudi) — 校园快递代取

📦 校园最后一公里快递代取平台 · React 前端模板

---

## 快速开始

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 技术栈

- **React 18** + **TypeScript**
- **Vite** 构建
- **Tailwind CSS** 样式
- **React Router** 页面路由

## 页面模板

| 页面 | 路由 | 功能 |
|------|------|------|
| 🏠 首页 | `/` | 附近待接单列表 |
| 📮 发布 | `/publish` | 发布代取订单 |
| 📋 订单 | `/orders` | 我的订单列表 |
| 👤 我的 | `/profile` | 个人中心 |
| 🔑 登录 | `/login` | 验证码登录 |

> 演示模式，使用模拟数据，无需后端即可运行
